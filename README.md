# User Profile Card – API Integration

## About the Project

A responsive User Profile Card application built using HTML, CSS, and JavaScript. It fetches user information from the DummyJSON API and displays it in a profile card. Users can click the **View Profile** button to see additional details in a modal dialog.

## Features

- Fetches user data from an external API.
- Displays the user's profile image, name, and email.
- Shows additional profile details, including age, gender, phone number, and address.
- Interactive profile modal with a close button.
- Responsive design for mobile, tablet, and desktop screens.
- Gradient styling and hover effects.
- Loading and error message handling.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Fetch API
- DummyJSON API

## How to Run the Project

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using the Live Server extension.
4. Click **View Profile** to explore the user's details.

Note: An internet connection is required to fetch user information from the API.
